# Magnus Academy – Invigilator Rota

Admin-led invigilator scheduling system.

## Admin flow
1. Select a season
2. Shift Setup → Notify invigilators
3. Assign Invigilators → Publish rota

## Invigilator flow
- View available shifts
- View my shifts
- View today’s invigilation team

This project is deployed using Vercel and Supabase.
